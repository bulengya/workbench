⚙️ 设置 · Supabase 云同步

填入你的 Supabase 项目信息即可多设备同步。不填则为纯本地模式（数据保存在本机浏览器，同样不会丢失）。

① 到 supabase.com 创建免费项目 → Settings → API，复制 URL 和 anon key。
② 在 SQL Editor 中执行以下建表语句（一次即可）： 
create table if not exists workbench (
  id text primary key,
  content jsonb,
  updated_at timestamptz default now()
);
alter table workbench enable row level security;
create policy "wb_all" on workbench
  for all using (true) with check (true);
③ 所有设备填同一个「同步码」，数据就会互通。
